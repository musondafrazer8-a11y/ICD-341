## Project description
This project investigates how rainfall, fertiliser use and time affect maize yield across eight Zambian districts (2010-2024), and how production risk changes under drier conditions. It combines descriptive statistics, OLS and fixed-effects regression, bootstrapping, Monte Carlo simulation, a Gaussian Mixture Model, and an interactive Streamlit dashboard.

> **Data warning:** `data/maize_production.csv` is **simulated** (`src/make_data.py`, seed 123) so the project is runnable. It is not official statistics. State this clearly in your submission, or replace it with real data (see below).

## Results (on the simulated data)
See `outputs/results_summary.txt` and the notebook. Headline: yield is positively associated with rainfall and fertiliser and rises over time; district fixed effects raise R² from about 0.48 to 0.74; a 100 mm rainfall drop lowers expected production by about 5%; BIC finds a single yield group. These reflect how the data were simulated and say nothing about real districts.

## Limitations
Simulated data; OLS ignores spatial/temporal correlation; median imputation is a simplification; Monte Carlo assumes normal inputs and a correct model.
